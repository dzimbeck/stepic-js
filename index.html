🔍 STEPIC Steganography

Encode messages into PNG images or extract hidden STEPIC data

About: This demo uses stepic.js to read and write the STEPIC RGB least-significant-bit format. Files are processed locally. Encoding accepts PNG, JPEG, BMP, and other images your browser can decode, and always produces a PNG. Animated carriers become a single static image. Decoding requires an 8-bit, non-interlaced RGB or RGBA STEPIC PNG.
⚠️ Note: STEPIC hides bytes; it does not encrypt or authenticate them. A detected end marker does not prove that an image contains an intentional message.
